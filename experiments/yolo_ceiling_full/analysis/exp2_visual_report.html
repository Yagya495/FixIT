FixIt Madison · YOLO26n-OBB experiment 2 · evaluation review

Ceiling Detector Review

Experiment 2 (155 training photos) on the same 50 held-out test images as experiment 1 and the current Llama 4 Maverick pipeline. Test findings use only the saved artifacts from the single test evaluation (confidence 0.25); threshold and hybrid tuning use the 36 validation images. Nothing was retrained or re-evaluated on test.

Verdict

  • Do not integrate YOLO as a standalone detector. Object-level recall is 0.13 at confidence 0.25 (29 of 230 damage boxes), and validation tuning cannot fix it (best F1 0.27).
  • A narrow hybrid looks useful: adding YOLO's crack/hole flags to Llama found surface damage in 20/29 test images versus 15/29 for Llama alone, with 2/21 false-positive images versus 0/21. Validation agrees in direction (+2 images, +1 false positive). For moisture, Llama alone is better.
  • The dataset is the main limit, not the model size. All 2,068 boxes are axis-aligned (the OBB format carries no orientation), the moisture classes are labelled on top of each other, holes are tiny, and copies of the same photo are labelled inconsistently.
  • Next experiment: fix the data (relabel a focused crack/hole/stain set, merge or define the moisture classes, add real clean ceilings and fixture negatives), not YOLO26s.

Diagonal cracks get large upright rectangles that are mostly clean ceiling, so a tight, correct prediction often fails the 0.5 overlap test. 46 boxes cover most of the image, and 473 cover less than 0.2%. These problems cap any model trained on this data and also make the scores understate some correct detections.

Recommendation

  • Keep Llama as the detector in the app. Don't integrate YOLO before the demo.
  • Next experiment: improve the dataset, not the model size. Relabel a focused set (cracks with rotated boxes, holes, stains; one consistent label per photo), merge damp + mold-like + stain or write clear rules for them, and add real clean ceilings plus vents, smoke detectors and lights as negatives. With 155 distinct photos and noisy labels, YOLO26s would mostly fit the noise; it is worth testing only after the data is fixed, or as a cheap side run (about 2 GPU minutes) that doesn't block the data work.
  • Also try a standard axis-aligned YOLO26 detector on the same split: the labels have no orientation, so it is the better-matched task.
  • Later, a hybrid crack/hole helper (YOLO at conf 0.25 OR Llama) could add surface recall, but confirm it on new photos first; the +5 images on test are from small samples.
