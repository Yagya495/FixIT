# FixIt Madison: 3-minute demo script (Databricks track)

Every Databricks claim below was verified on our Free Edition workspace on 2026-11-14 (see PROGRESS.md). **Don't say
anything that isn't in this script about AI accuracy, legal effect, or features we haven't built.**

Presenter (P) drives the laptop; Teammate (T) plays the landlord on the call. App:
https://fixit-madison-7474647207905142.aws.databricksapps.com

## Before you start (T-15 min)
1. Open the App and click **Continue** on the Databricks authorization screen. This warms the SQL warehouse (a cold one adds ~10 s).
2. Reset the data: `python scripts/dbx_setup.py --profile fixit --warehouse 6361516ab33ba2d2 --catalog fixit --only reset --apply`
3. If the stage photos were warmed (`POST /api/demo/warm`), uploads show "Saved result from an earlier live analysis".
   If not, they show "Analyzed live just now…" (2–15 s). Either is honest; know which one you'll see.
4. Tabs: `/listing`, `/scan`, `/city`, `/about`. Volume up. Browser zoom 110%.

### Optional live-Genie beat (adds ~20 s)
Type a new question (e.g. "How many buildings does Isthmus Edge Properties (demo) own?"). It goes to Genie live (≈17–24 s);
the caption reads "Answered live by Databricks Genie." Talk over the wait about the gold tables and table comments.

## Words to avoid
- ❌ "violation found", "code violation detected", "inspection" → ✅ "possible issue", "spotted", "only an inspector can confirm"
- ❌ "legal deadline", "the landlord must by law" → ✅ "FixIt reminder", "the date they promised"
- ❌ "files a complaint", "submits to the city" → ✅ "drafts", "pre-fills; you submit"
- ❌ "real landlord data", "these tenants" → ✅ "synthetic demo data"
- ❌ "the AI is X% accurate" (until `scripts/eval_vision.py` has run on real photos, and then quote the sample size)
- ❌ "Vector Search", "MLflow", "risk model", "real phone calls" (not built/enabled)

## If something goes wrong
| Problem | Do |
|---|---|
| Photo analysis slow (>15 s) | Keep talking about Volumes and hashing; Demo Mode falls back automatically if it fails |
| Live model finds nothing in a photo | Use **Report no heat** to continue the flow; say "the model didn't flag that one, so it's honest" |
| App unreachable / auth problem | Local fallback: `python -m uvicorn app.backend.main:app --port 8000` (SQLite, same story) |
| Voice silent | Transcript is on screen; continue |
| Genie slow | Use a sample question (saved answer, instant) |
